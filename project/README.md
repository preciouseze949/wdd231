# Mrpee Shoes

**WDD 231 Individual Website Project**  
**Author:** Precious Anietem

## Project overview

Mrpee Shoes is a footwear website concept showcasing formal shoes,
casual footwear, sandals, sneakers, and custom shoe options.

**Slogan:** Crafted for Comfort. Designed for Style.

## Website pages

- `index.html` — homepage and featured products
- `collections.html` — searchable and filterable product catalogue
- `contact.html` — customer enquiry form
- `form-action.html` — demonstration form submission results
- `attributions.html` — external resource credits
- `siteplan.html` — original website planning document

## Project structure

- `css/small.css` — mobile-first styles
- `css/large.css` — tablet and desktop styles
- `js/main.js` — homepage product display
- `js/collections.js` — catalogue filtering and product details
- `js/contact.js` — contact form initialization
- `js/form-action.js` — form results display
- `js/modules/site.js` — shared navigation and footer functions
- `js/modules/storage.js` — localStorage favorites
- `data/shoes.json` — product catalogue

## Technologies

- HTML5
- CSS3
- JavaScript ES modules
- JSON and Fetch API
- localStorage
- Google Fonts

## Running the project

Run the project through a local development server or deploy it to
GitHub Pages. Fetch requests for `data/shoes.json` may not work when
opening the HTML files directly through a `file://` URL.

## Deployment

Publish the project folder using the GitHub Pages settings for the
repository.

Replace placeholder URLs in the HTML files with the actual published
project URL before submitting.

## Important notes

- Product prices are illustrative and are not confirmed retail prices.
- Product images must be checked against their original source pages.
- The contact form demonstrates browser-based form submission only.
  It does not send emails or store enquiries on a server.
- Replace the demonstration video link with the actual project video URL.
